# kit-design

Inspect the existing design system and target screen. --screenshot uses an attached reference; --describe explains the visual; --3d uses Three.js when appropriate; --video uses a product demo reference. Choose responsive layout, accessible controls and useful states. Verify in the browser with an app-specific locator or response; capture evidence where useful. External generation tools are optional.

Treat mode flags as task parameters. Preserve user scope and existing instructions. Use equivalent host tools. Hand off the outcome, changed paths, checks and remaining uncertainty.
